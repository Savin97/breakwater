Crontab (crontab -e):

NOTE: always invoke cron scripts as `cd /var/www/breakwater && .../python -m cron.<module>`,
never by direct file path (`python cron/cron_iv.py`) — a direct path invocation puts cron/
on sys.path instead of the repo root, so `from config import DB_PATH` fails with
ModuleNotFoundError. This silently broke cron_iv/cron_eps_estimates from ~2026-06-29 to
2026-08-02 (every run failed immediately, no cron mail configured to surface it).

# IV snapshots — 4x daily during market hours (10am, 12pm, 2pm, 3:30pm ET)
0 14,16,18 * * 1-5 cd /var/www/breakwater && /var/www/breakwater/.venv/bin/python -m cron.cron_iv >> /var/log/breakwater/iv.log 2>&1
30 19      * * 1-5 cd /var/www/breakwater && /var/www/breakwater/.venv/bin/python -m cron.cron_iv >> /var/log/breakwater/iv.log 2>&1

On the server (cv_website / Streamlit):

cd /var/www/cv_website
git pull

If you changed only index.html, styles.css, images, etc.:

systemctl reload nginx

If you changed app.py, streamlit_df.csv, or Python code used by Streamlit:

systemctl restart breakwater

If you changed requirements.txt:

cd /var/www/cv_website
source .venv/bin/activate
pip install -r requirements.txt
systemctl restart breakwater

Typical update flow:

cd /var/www/cv_website
git pull
source .venv/bin/activate
pip install -r requirements.txt
systemctl restart breakwater
