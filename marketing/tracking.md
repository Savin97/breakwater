# Breakwater Marketing Tracking

## No Analytics Script Yet

Do not add Google Analytics, Plausible, or another third-party analytics script until there is a clear reason. For now, use UTM links and a weekly manual review.

## UTM Conventions

Use these query parameters in public posts:

- X weekly radar: `?utm_source=x&utm_medium=social&utm_campaign=weekly_radar`
- X results post: `?utm_source=x&utm_medium=social&utm_campaign=results`
- X ticker breakdown: `?utm_source=x&utm_medium=social&utm_campaign=ticker_breakdown`
- Reddit comment: `?utm_source=reddit&utm_medium=community&utm_campaign=earnings_risk`
- Direct outreach: `?utm_source=outreach&utm_medium=dm&utm_campaign=beta`

## Weekly KPI Sheet

Create one row per week with these columns:

- week_start
- email_subscribers_start
- email_subscribers_end
- new_subscribers
- digest_sent
- digest_opens
- digest_clicks
- dashboard_visits
- x_posts
- best_x_post_url
- best_x_post_impressions
- best_x_post_engagements
- subscriber_replies
- user_conversations
- premium_beta_requests
- notes

## 90-Day Targets

- Day 30: measurable signup flow and first 50-100 subscribers, or a clear diagnosis of why conversion is weak.
- Day 60: at least 10 user conversations and evidence of repeat digest engagement.
- Day 90: 5-10 users actively using Breakwater across multiple earnings weeks and 3+ serious pricing conversations.

## Weekly Review Questions

- Which source produced the highest-quality subscribers?
- Did subscribers return after the first digest?
- Which audience described the sharpest use case?
- What did users ask for before they would pay?
- Which public proof format produced the best response?
